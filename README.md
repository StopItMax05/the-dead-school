# The Dead School — live build

Play it here: **https://stopitmax05.github.io/the-dead-school/**

A first-person horror escape for desktop browsers and iPad Safari. Use headphones. Chrome, Edge, Firefox or Safari with WebGL2.

This repository holds only the built game, published with GitHub Pages. The source code lives in the private repository jmcewan-ava/MAXGAME; this build is from commit 556acd5. To redeploy: build the source with `npx vite build --base=/the-dead-school/`, copy `dist/` here, commit and push.

`The-Dead-School.html` is the self-contained offline copy (download it with "Download raw file" and open it in a desktop browser). `LICENSES.txt` lists the dependency notices for the PlayCanvas engine and Ammo physics.
